Six weeks, one ship item

Learner workbook

Draft, not yet run with any learner. Hours and minutes are provisional numbers. What you type in the boxes is saved on this device straight away. You can also write in another tool, as long as you keep the record.

The whole course has one thread: your ship item. Each week the ship item moves one milestone, and every concept is taught only as far as it takes to pass that milestone.

Week by week

Each page holds the learner brief, the Session 1 exercises and the self-work for that week. The second column is the ship item milestone of the week.

  • W0Before Week 1: Entry taskIntake interview preparation; two candidate problems; manager note
  • 1One problem, one numberProblem frame; candidate number
  • 2Two-way: business and technicalSettle the number, start measuring the baseline window; spec with acceptance criteria
  • 3What the agent readsOntology for the work area; first part of the ship item is built
  • 4One-person company (OPC)First version that passes a grader agent against the acceptance criteria
  • 5Evidence over assertionPasses the gate, then goes to 1 or 2 colleagues; at the end of the week it ships to real users
  • 6DefenceShip deadline; oral defence
