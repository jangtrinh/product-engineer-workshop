Model and examples · the model in plain words · minutes 0–5

Six rules of the model

1

Each agent has exactly one job and one prohibition

2

A reversible task is run by the agent on its own

3

An irreversible task is approved by a person by hand

4

The maker and the grader are two different sessions

5

The whole team reads the same ontology

6

Accountability goes up the chain: an agent never bears it

Merge or deploy without an OK

Executing agent: never

The prohibition names an action. It does not say “be careful”. The last two lines separate the maker from the grader.
