Which sentence is a usable problem frame?

A

“Need to add a filter to the report page.”

B

“The accountant spends about 2 hours a week filtering the report by hand; done when filtering takes 10 minutes, measured with a stopwatch three times.”

C

“The report is slow and hard to use at the moment.”

D

“The number of tickets closed each week
rises by 20%, measured by the ticket system.”

Choose first, then explain. The numbers are constructed.
